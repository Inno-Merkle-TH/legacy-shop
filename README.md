# Demo Store

เว็บร้านค้าจำลองสำหรับฝึกทดสอบ QA และ automation ใช้ Node.js, HTML, CSS และ JavaScript โดยไม่มี dependency ภายนอก

## วิธีรัน

ใช้ Node.js 18 ขึ้นไป แล้วรัน:

```sh
npm start
```

เปิด http://127.0.0.1:3000

บัญชีทดลอง: `demo@legacy.test` / `demo1234`

เปลี่ยนพอร์ตได้ด้วย:

```sh
PORT=3001 npm start
```

ต้องเปิดเว็บผ่านเซิร์ฟเวอร์ ไม่ใช่เปิดไฟล์ HTML โดยตรง กด Ctrl+C เพื่อหยุดเซิร์ฟเวอร์

## หน้าจอ

- เข้าสู่ระบบ
- สมัครสมาชิก
- รายการสินค้า
- ตะกร้าสินค้า
- ยืนยันคำสั่งซื้อ

ใช้ข้อมูลทดลองเท่านั้น ไม่มีการเรียกเก็บเงินหรือจัดส่งสินค้าจริง

## ชุดทดสอบพื้นฐาน

```sh
npm test
```

ชุดทดสอบพื้นฐานใช้ `node:test` สำหรับ HTTP API และ client logic ไม่ครอบคลุมการใช้งานทั้งหมดหรือการแสดงผลในเบราว์เซอร์
